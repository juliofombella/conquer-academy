Tu primer repositorio en GitHub

Publicado el 18 de noviembre de 2026 por Laura Ortega.

Git es un programa que guarda el historial de cambios de tu proyecto. GitHub es una web donde puedes subir ese proyecto para tener una copia en internet y enseñárselo a otras personas. Si nunca has subido nada, en este artículo lo hacemos desde cero.

Antes de empezar

Necesitas tener Git instalado. Si es la primera vez que lo usas en ese ordenador, dile también quién eres: escribe en la terminal git config --global user.name "Tu nombre" y, después, git config --global user.email "tu email". Pon el mismo email con el que te registres en GitHub, así tus cambios saldrán asociados a tu cuenta.

Paso a paso

  1. Crea una cuenta gratuita en GitHub.
  2. En GitHub, pulsa en el + de arriba a la derecha y elige «New repository». Ponle un nombre y déjalo vacío, sin README, .gitignore ni licencia. Si GitHub crea algún archivo, la subida del paso 8 dará error.
  3. Abre la terminal en la carpeta de tu proyecto y escribe git init. Con esto, la carpeta pasa a ser un repositorio de Git.
  4. Escribe git add . para preparar todos los archivos. El punto quiere decir «todo lo que hay en esta carpeta».
  5. Guarda la primera versión con git commit -m "Primer commit". El texto entre comillas es el mensaje que explica qué has hecho.
  6. Escribe git branch -M main para que tu rama principal se llame main, como en GitHub.
  7. Conecta la carpeta con el repositorio de GitHub: git remote add origin https://github.com/tu-usuario/tu-repositorio.git. La dirección exacta la copias de la página del repositorio.
  8. Sube el proyecto con git push -u origin main. La primera vez, Git te pedirá que inicies sesión en GitHub.

Recarga la página del repositorio y verás tus archivos. A partir de ahora, cuando cambies algo, repite los pasos 4 y 5 con otro mensaje y escribe solo git push: gracias al -u de la primera vez, Git ya sabe adónde tiene que subir los cambios.
