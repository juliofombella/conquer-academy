Bases de datos con SQL

SQL es el lenguaje que se usa para trabajar con bases de datos relacionales, que organizan la información en tablas con filas y columnas. En este curso de nivel principiante lo aprendes en 6 semanas (unas 30 horas).

Qué vas a aprender

Empiezas creando tus propias tablas y llenándolas de datos. Después aprendes a hacerle preguntas a la base de datos para que te devuelva solo lo que te interesa. En el proyecto final, la base de datos de una biblioteca, podrás responder a preguntas como estas:

  • ¿Cuántos libros hay de cada autor?
  • ¿Qué socios tienen un libro sin devolver?
  • ¿Qué libros se han prestado este mes?

Para responderlas usarás SELECT junto con WHERE, GROUP BY y JOIN.
